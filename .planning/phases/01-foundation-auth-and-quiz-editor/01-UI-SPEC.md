# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundation, Auth & Quiz Editor.
> Generated by gsd-ui-researcher. Covers requirements AUTH-01–03, QUIZ-01–07, EDIT-01–08, NAV-01–02.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | shadcn-vue | D-18 (CONTEXT.md) |
| Preset | source-copy approach — no CLI preset; add components individually via `npx shadcn-vue@latest add <component>` | D-18 |
| Component library | radix-vue (shadcn-vue is built on it) | D-18 |
| Icon library | lucide-vue-next (standard with shadcn-vue) | Claude's Discretion (CONTEXT.md) |
| Font | Inter (Google Fonts) | SPEC.md |
| CSS framework | Tailwind CSS v4 | CLAUDE.md / STACK.md |

**shadcn-vue components required for Phase 1:**
- `Button` — primary CTA, destructive actions, secondary actions
- `Input` — auth form fields, quiz metadata text fields, question textarea, answer option fields
- `Dialog` — quiz/question delete confirmation
- `Tabs` — auth page login/register toggle
- `Toggle` / `Switch` — publish toggle, `allow_back` toggle, `show_stop_button` toggle, `is_required` toggle
- `Toast` (via vue-sonner) — all feedback notifications
- `Tooltip` — DnD handle hint, icon-only button labels

**Toast library choice:** vue-sonner (wraps Sonner; pairs naturally with shadcn-vue; recommended over radix-vue's own toast for simpler setup in Vue 3).

## Spacing Scale

Declared values (multiples of 4, 8-point grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, tight inline gaps |
| sm | 8px | Compact element spacing, button icon gap, answer option row internal gap |
| md | 16px | Default element spacing, card padding, form field gap |
| lg | 24px | Section padding, card-to-card gap, editor panel padding |
| xl | 32px | Layout gaps, header/footer padding, section breaks |
| 2xl | 48px | Major section breaks, empty state vertical centering offset |
| 3xl | 64px | Page-level vertical spacing, hero areas |

**Exceptions:**
- Touch targets (drag handle, icon-only buttons, toggle controls): minimum 44px hit area (accessibility requirement). Visual size may remain 20px; padding compensates.
- Editor body inner padding: `px-6 py-6` (24px) to give question cards visual breathing room.
- Cover upload zone: minimum height 120px (fixed); aspect ratio 16:9 or free depending on uploaded image.

## Typography

Font: Inter (Google Fonts, loaded via `<link>` in `index.html`).
Tailwind v4 config: `@theme { --font-sans: 'Inter', sans-serif; }` in `main.css`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Answer option text, helper text, descriptions, toast messages |
| Label | 16px | 400 (regular) | 1.5 | Form inputs, question text textarea, card body text |
| Heading | 20px | 600 (semibold) | 1.2 | Card titles, section headings, dialog titles, quiz title in header |
| Display | 28px | 600 (semibold) | 1.2 | Page-level headings (`/my`, `/`), auth page title |

**Exactly 2 weights in use: 400 and 600.** No 500, no 700.

## Color

Reference: app.promto.ai minimalism — light-mode-first, clean surfaces, violet/indigo brand accent.
Dark mode is planned (STACK.md: `@custom-variant dark` with `.dark` class on `<html>`) but Phase 1 ships light mode only. All tokens use CSS custom properties via Tailwind v4 `@theme` for future dark mode compatibility.

| Role | Light Value | Usage |
|------|-------------|-------|
| Dominant (60%) | `#ffffff` (white) / `#f9fafb` (gray-50 for page bg) | Page background, modal backgrounds, main surface |
| Secondary (30%) | `#f3f4f6` (gray-100) | Card backgrounds, sidebar (if any), input backgrounds, footer panel |
| Accent (10%) | `from-violet-600 to-indigo-600` gradient | See reserved-for list below |
| Destructive | `#ef4444` (red-500) | Delete quiz button, delete question button, destructive dialog confirm |
| Border | `#e5e7eb` (gray-200) | Card borders, input borders, dividers |
| Text primary | `#111827` (gray-900) | Headings, primary body copy |
| Text secondary | `#6b7280` (gray-500) | Helper text, placeholder text, meta info |
| Success | `#10b981` (emerald-500) | Published status badge, toast success |
| Warning | `#f59e0b` (amber-500) | Validation warning messages (reserved for Phase 3+; defined now for consistency) |

**Accent reserved for exactly these elements:**
1. Primary CTA button ("Создать тест", "Опубликовать", "Сохранить и опубликовать", "Войти", "Зарегистрироваться") — gradient fill `bg-gradient-to-r from-violet-600 to-indigo-600`
2. "Создать первый тест" button on `/my` empty state
3. "Добавить вопрос" primary action button in editor body
4. Active/checked state of `is_correct` answer option radio/checkbox indicator

Accent is NOT used on: nav links, secondary buttons (those use `variant="outline"`), toggles, breadcrumbs.

## Component Anatomy

### AuthPage (`/auth`)

**Layout:** Centered card, max-width 400px, `mx-auto mt-20` (80px top margin), `p-8` (32px padding), white card on gray-50 background.

**Toggle mechanism:** Two text links at card top — "Войти" and "Зарегистрироваться" — rendered as `Tabs` from shadcn-vue. Active tab renders the corresponding form. No URL change on toggle (single route `/auth`).

**Login form fields (in order):**
1. `<Input type="email" placeholder="Email" autocomplete="email" />` — full width
2. `<Input type="password" placeholder="Пароль" autocomplete="current-password" />` — full width
3. `<Button>` primary gradient — "Войти" — full width, `mt-4`

**Register form fields (in order):**
1. `<Input type="email" placeholder="Email" autocomplete="email" />` — full width
2. `<Input type="password" placeholder="Пароль" autocomplete="new-password" />` — full width
3. `<Button>` primary gradient — "Зарегистрироваться" — full width, `mt-4`

**No additional fields.** No full_name, no "Remember me", no OAuth (D-04).

**Form states:**
- Default: fields empty, button enabled
- Loading: button shows spinner icon (Lucide `Loader2` with `animate-spin`), button disabled
- Error: toast notification (red, top-right) with error message — no inline field errors for auth
- Success: redirect fires immediately, no success state shown

**Route guard result:** If unauthenticated user hits `/my` or `/editor/:id`, redirect to `/auth?returnUrl=<original>`. After auth success, `router.push(returnUrl || '/')`.

---

### QuizCard (shared between `/` and `/my`)

**Card dimensions:** Full width within grid cell. Min-height: none (let content determine height). Padding: `p-4` (16px).

**Card anatomy (top to bottom):**
1. Cover image: aspect-ratio `16/9`, `object-cover`, `rounded-md`, `mb-3`. If no cover: gray-100 placeholder rectangle with centered Lucide `Image` icon in gray-400. Same dimensions.
2. Quiz title: `text-heading` (20px/600), gray-900, `line-clamp-2`, `mb-1`
3. Quiz description (if set): `text-body` (14px/400), gray-500, `line-clamp-2`, `mb-2`
4. Meta row: question count + (optional) time limit — `text-body` (14px), gray-400. Example: "5 вопросов · 10 мин"
5. `/my` only — action row at bottom: `flex justify-end gap-2 mt-3`. Contains:
   - "Редактировать" link button (`variant="ghost"`, Lucide `Pencil` icon, opens `/editor/:id`)
   - "Удалить" button (`variant="ghost"`, destructive color, Lucide `Trash2` icon, triggers confirmation dialog)
   - Published badge (`is_published: true` → green badge "Опубликован"; `false` → gray badge "Черновик")

**Hover state:** `hover:shadow-md transition-shadow duration-150`. Card background stays white; no color fill change.

**Grid layout for both pages:** `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6`. Max-width container: `max-w-6xl mx-auto px-6`.

### Empty State (`/my`, no quizzes)

**Layout:** Centered vertically and horizontally within the page main area. `flex flex-col items-center justify-center` with `min-h-[400px]`.

**Anatomy:**
1. Lucide `FileQuestion` icon, size 64px, color gray-300
2. Heading: "У вас пока нет тестов" — `text-display` (28px/600), gray-900, `mt-6`
3. Body: "Создайте первый тест и начните делиться им с участниками." — `text-label` (16px/400), gray-500, `mt-2 text-center max-w-sm`
4. CTA button: "Создать первый тест" — primary gradient `<Button>`, `mt-8`, Lucide `Plus` icon left of label

Source: D-08 (CONTEXT.md).

### QuizEditorPage (`/editor/:id`)

**Page layout:** CSS Grid, `height: 100dvh`, `display: grid`, `grid-template-rows: auto 1fr auto`, `overflow: hidden`. Use `100dvh` not `100vh` (ARCHITECTURE.md: mobile browser chrome adjustment).

#### Editor Header (fixed top, `auto` row)

Background: white. Bottom border: `border-b border-gray-200`. Padding: `px-6 py-4`.

**Header anatomy (left to right, two-line structure):**

Line 1:
- Back arrow: Lucide `ArrowLeft`, `variant="ghost"`, links to `/my`. Wrapped in `<Tooltip>` with content "Вернуться к списку тестов". Element must declare `aria-label="Вернуться к списку тестов"`.
- Quiz title: `<Input>` inline, `text-heading` (20px/600), borderless in default state (appears as plain text), shows border on focus. Placeholder: "Без названия". Auto-saves on blur with 500ms debounce.
- Publish toggle: right-aligned. Uses shadcn-vue `Switch` component. Label: "Черновик" when off, "Опубликован" when on. Color: gray when off, green (emerald-500) when on. Clicking "Опубликовать" when validation fails → toast error listing missing requirements.

Line 2 (metadata row, collapsible into one horizontal strip):
- Description field: `<Input>` full width (or `<textarea rows="2">`), placeholder "Описание теста (необязательно)". Auto-saves on blur.
- Time limit: numeric `<Input>` + "мин" suffix label, placeholder "—", `w-20`. Auto-saves on change with 500ms debounce. Null = no limit.
- Cover upload zone (see Cover Upload below).

#### Editor Body (scrollable `1fr` row)

`overflow-y: auto`, `overscroll-behavior: contain`. Background: gray-50. Padding: `px-6 py-6`.

Contains:
1. `<VueDraggable>` wrapping the questions list. `handle=".drag-handle"`.
2. Question cards (see QuestionCard below).
3. "Добавить вопрос" button at bottom of list — primary gradient, Lucide `Plus` icon, `mt-4`. On click: INSERT new question, append to list, auto-scroll to it, textarea gets focus (D-10).

#### Editor Footer (fixed bottom, `auto` row)

Background: white. Top border: `border-t border-gray-200`. Padding: `px-6 py-4`.

**Footer anatomy — Navigation Settings panel:**

Label: "Настройки навигации для тестируемого" — `text-label` (16px/600), gray-700.

Two toggle rows:
1. `<Switch>` + label "Разрешить возврат к предыдущему вопросу" — maps to `settings.allow_back`
2. `<Switch>` + label "Показывать кнопку «Стоп»" — maps to `settings.show_stop_button` (add to `quizzes.settings` JSONB)

Toggles: default state from DB value. Auto-save on change (immediate, no debounce — boolean toggle).

### QuestionCard

**Card container:** White background, `rounded-lg border border-gray-200`, `p-4 mb-4`, `shadow-sm`. Always expanded — never collapsible (D-09).

**Card anatomy (top to bottom):**

Row 1 — Question header:
- Drag handle: Lucide `GripVertical` icon, gray-300, `cursor-grab`. Class `.drag-handle` for SortableJS. Minimum touch target 44px. `hover:text-gray-500`.
- Question number: "Вопрос N" — `text-body` (14px/400), gray-400.
- Question type toggle (right-aligned): segmented control — two options "Один ответ" / "Несколько ответов". Use two `<Button variant="outline">` buttons that behave as a toggle group. Active state: `bg-violet-50 border-violet-400 text-violet-700`.
- Required toggle: `<Switch>` + label "Обязательный" — maps to `is_required`.
- Delete button: Lucide `Trash2`, `variant="ghost"`, destructive color (red-500). Triggers confirmation dialog (D-11).

Row 2 — Question text:
- `<textarea>` full width, `min-h-[80px]`, auto-resize (grows with content). Placeholder: "Введите текст вопроса...". `text-label` (16px/400). Auto-saves on blur with 500ms debounce.

Row 3 — Answer options list:
- Each option row (see AnswerOptionRow below).
- "Добавить вариант" link button: Lucide `Plus` icon + "Добавить вариант ответа" text, `variant="ghost"`, `text-body` (14px), gray-500. Appended below last option.

---

### AnswerOptionRow

**Row layout:** `flex items-center gap-2`, `py-1`.

**Anatomy (left to right):**
1. Correct-answer indicator:
   - `type = 'single'`: radio circle. Unchecked: `border-gray-300 bg-white`. Checked: `border-violet-600 bg-violet-600` with white dot. Clicking marks this option correct and unmarks all others.
   - `type = 'multiple'`: checkbox. Unchecked: `border-gray-300 bg-white`. Checked: `bg-violet-600 border-violet-600` with white checkmark (Lucide `Check`).
2. Answer text: `<Input>` full width, borderless-style in default, shows subtle border on focus. Placeholder: "Вариант ответа". `text-body` (14px/400). Auto-saves on blur.
3. Delete button: Lucide `X`, `variant="ghost"`, size sm, gray-400. No confirmation — immediate delete (D-11). Wrapped in `<Tooltip>` with content "Удалить вариант". Element must declare `aria-label="Удалить вариант"`.

**Saving:** `answer_options` row upserts to Supabase on every blur. No batch save.

---

### Cover Upload Zone

**Placement:** Within editor header, right section or below metadata fields.

**Default state (no cover, D-15):**
- Dashed border `border-2 border-dashed border-gray-300`, `rounded-lg`, `bg-white`.
- Dimensions: `w-full max-w-xs h-28` (112px height).
- Centered content: Lucide `ImagePlus` icon (gray-300, 32px) + "Добавить обложку" label (`text-body` 14px, gray-400). No background gradient.
- Cursor: `cursor-pointer`.
- Accepts: click-to-open file picker OR drag-and-drop (D-14).

**Drag-over state:**
- Border changes to `border-violet-400`. Background: `bg-violet-50`. Text changes to "Отпустите для загрузки".

**Uploading state:**
- Same dimensions. Shows `Loader2 animate-spin` icon (gray-400) + "Загружается..." text. Not interactive during upload.

**Uploaded state (cover present):**
- Image replaces zone: `<img>` with `object-cover rounded-lg` same dimensions.
- On hover: overlay with `bg-black/40`, centered Lucide `Camera` icon (white) + "Изменить" label. Click opens file picker.
- "Удалить обложку" button: `<Button variant="ghost" size="sm">` below image, red-500 text.

**Validation (D-17):** JPEG/PNG/WebP only. Max 5MB. Resize to max 1280px wide on client (canvas API) before upload. Reject other formats with toast error: "Поддерживаются только JPEG, PNG и WebP. Максимальный размер — 5 МБ."

### Navigation Bar (AppHeader / AppNav)

**Placement:** Top of every page except the editor (editor has its own full-height layout with its own header).

**Height:** 56px (`h-14`). Background: white. Bottom border: `border-b border-gray-200`. `sticky top-0 z-40`.

**Anatomy (left to right):**
- Logo / brand: "Quiz Flow" text or simple SVG mark, `text-heading` (20px/600), violet-600. Links to `/`.
- Nav links (center or left after logo):
  - "Все тесты" → `/`
  - "Мои тесты" → `/my` (visible only when authenticated)
- Right side:
  - Unauthenticated: "Войти" `<Button variant="outline">` → `/auth`
  - Authenticated: user email (gray-500, truncated) + "Выйти" `<Button variant="ghost">` (AUTH-03 — logout from any page)

### Toast Notifications

**Library:** vue-sonner. Position: top-right. `z-index: 9999`.

**Variants and usage:**

| Variant | Trigger | Example copy |
|---------|---------|-------------|
| Success | Quiz created, published, unpublished, cover uploaded, question saved | "Тест опубликован" |
| Error | Auth failure, save failure, publish validation failure, upload error | "Ошибка сохранения. Проверьте соединение." |
| Info | Auto-save in progress (optional, debounced) | "Сохраняется..." |

**Duration:** Success: 3000ms. Error: 5000ms (requires deliberate dismissal or longer read time). Info: 2000ms.

All user-facing toast copy is in Russian (D-12).

---

### Delete Confirmation Dialog

**Component:** shadcn-vue `Dialog`.

**For quiz deletion (D-07):**
- Title: "Удалить тест?"
- Body: "Это действие нельзя отменить. Все вопросы и настройки теста будут удалены."
- Actions: `<Button variant="destructive">Удалить</Button>` + `<Button variant="outline">Оставить тест</Button>`
- `window.confirm` is acceptable for v1 but the spec calls for a custom dialog to avoid native browser styling inconsistency. Use shadcn-vue `Dialog`.

**For question deletion (D-11):**
- Title: "Удалить вопрос?"
- Body: "Вопрос и все варианты ответов будут удалены."
- Actions: `<Button variant="destructive">Удалить</Button>` + `<Button variant="outline">Оставить вопрос</Button>`

**Dialog width:** `max-w-md`. `sm:max-w-[425px]`.

## Responsive Breakpoints

Phase 1 ships desktop-first. Mobile layout is not the primary target for the quiz editor (editor UX requires screen real estate). However, the quiz list pages and auth page must be usable on mobile.

| Breakpoint | Value | Applied To |
|------------|-------|-----------|
| sm | 640px | Card grid: 1-col → 2-col |
| lg | 1024px | Card grid: 2-col → 3-col |
| (editor) | desktop only | QuizEditorPage is designed for ≥768px. Below 768px: show a notice "Редактор доступен только на десктопе" instead of rendering the editor. |

Mobile notice for editor (below 768px): centered card with Lucide `Monitor` icon + "Для редактирования теста откройте страницу на компьютере."

## Auto-Save Contract

| Field | Trigger | Debounce | Failure behavior |
|-------|---------|----------|-----------------|
| Quiz title | input event | 500ms | Toast error; no data loss (retry on next change) |
| Quiz description | blur | 500ms | Toast error |
| Time limit | input event | 500ms | Toast error |
| Question text | blur | 500ms | Toast error |
| Answer option text | blur | none (on blur) | Toast error |
| `is_required` toggle | change | none (immediate) | Toast error |
| `allow_back` toggle | change | none (immediate) | Toast error |
| `show_stop_button` toggle | change | none (immediate) | Toast error |
| Question type | change | none (immediate) | Toast error |
| `is_correct` marking | change | none (immediate) | Toast error |
| DnD reorder | `@end` handler | none (immediate batch upsert) | Toast error; local state preserved |
| Cover upload | after file picked/dropped | none (immediate upload) | Toast error with format/size reason |

Auto-save debounce interval: 500ms (Claude's Discretion, per ARCHITECTURE.md recommendation).
