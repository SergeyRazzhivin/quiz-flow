    2. Parses `{ token, login, password }` from the JSON body; rejects malformed input.
    3. Creates a service_role client from `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY`.
    4. Selects the `quiz_access` row by `token` AND `login` (selecting `id, quiz_id, password_hash, expires_at`).     9. Otherwise `signGuestToken({ quiz_access_id: access.id, quiz_id: access.quiz_id })` and return HTTP 200 `{ state: 'ready', guestToken, quiz: <metadata without questions>, questions }`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Guest browser -> verify-quiz-access EF | Untrusted token/login/password crosses here; no Supabase Auth |
| verify-quiz-access EF -> Postgres (service_role) | service_role bypasses RLS — EF must hand-filter sensitive columns |
| EF response -> guest browser | Response body must be free of is_correct / password_hash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | guest token forgery | mitigate | HS256 JWT signed with GUEST_JWT_SECRET (server-only); jwtVerify rejects bad signatures; verifyGuestToken returns null on any failure |
| T-02-02 | Information Disclosure | is_correct leaking to guest | mitigate | verify-quiz-access queries answer_options_public view only; never the base table; grep gate in Task 3 verify asserts this |
| T-02-03 | Information Disclosure | password_hash leaking to guest | mitigate | password_hash selected only for bcrypt.compare, never placed in response JSON |
| T-02-04 | Elevation of Privilege | password brute-force on quiz_access | mitigate | bcrypt cost factor 10 slows attempts; Supabase rate-limits EF calls; identical 401 message for "not found" and "wrong password" removes the enumeration oracle |
| T-02-05 | Information Disclosure | token enumeration via /q/:token scan | accept | quiz_access.token is UUID v4 (122 bits entropy) — 2^122 search space makes enumeration infeasible; no extra control needed |
| T-02-06 | Tampering | npm/Deno package supply chain (jose, bcryptjs, supabase-js) | mitigate | jose and supabase-js are [VERIFIED] in RESEARCH Package Legitimacy Audit; bcryptjs is [ASSUMED] — the _probe-bcrypt function + blocking human checkpoint verify it before any password flow ships |
</threat_model>
