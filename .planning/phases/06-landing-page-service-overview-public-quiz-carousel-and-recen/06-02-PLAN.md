## STRIDE Threat Register

This is a frontend-only phase: no DB migrations, no Edge Functions, no data mutations,
no auth flow changes. The threat surface is minimal and documented honestly.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Information disclosure | QuizCarousel data render | accept | Carousel renders only `is_published=true` quizzes via fetchCarouselQuizzes' explicit select list — no `is_correct`, no `password_hash`, no owner-private fields. Same public surface QuizListPage already exposes. |
| T-06-04 | Elevation of privilege | / and /quizzes routes | accept | Both routes are intentionally public (D-01/D-02); they assemble display-only widgets and trigger no privileged operation. Auth-gated routes (/my, /editor, /billing) keep their existing `requiresAuth` guard, unchanged by this plan. |
| T-06-05 | Denial of service | QuizCarousel setInterval | mitigate | The auto-advance interval and the resize listener are cleared/removed in onUnmounted (RESEARCH Pitfall 3) so navigating away cannot accumulate runaway timers. |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed this phase (RESEARCH Package Legitimacy Audit: none). No install task exists. |
</threat_model>
