## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip padding |
| sm | 8px | Compact inline spacing, card gap |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section inner padding, nav gaps |
| xl | 32px | Layout column gaps, hero sub-gap |
| 2xl | 48px | Between landing sections (`py-12`) |
| 3xl | 64px | Hero vertical padding (`py-16`) |

Exceptions:
- Hero section on desktop: `py-20` (80px) acceptable to create breathing room above the fold
- Carousel prev/next touch targets: min 44px × 44px (accessibility minimum)
- Max-width container for all sections: `max-w-6xl mx-auto px-6` (matches `AppHeader` and `QuizListPage`)

Source: `AppHeader.vue` (`px-6 max-w-6xl`), `QuizListPage.vue` (`py-8 px-6`), inferred 8-pt scale.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 |
| Label / caption | 14px (`text-sm`) | 400 (regular) | 1.4 |
| Heading (section title) | 20px (`text-xl`) | 600 (semibold) | 1.3 |
| Display (hero headline) | 36px (`text-4xl`) or 48px (`text-5xl` on md+) | 600 (semibold) | 1.15 |

Notes:
- Hero sub-headline: Body role — 16px (`text-base`), weight 400, `text-neutral-400`, line-height 1.5. The muted colour provides sufficient visual separation from the headline.
- Card title (`QuizCard.vue`): 14px semibold — unchanged, no override needed.
- "Как это работает" step labels: 16px semibold (`text-base font-semibold`).
- Step counter badges: 14px semibold, gradient text or `text-orange-400`.
- Pricing teaser plan name ("Free", "Pro"): 20px semibold.

Source: `QuizCard.vue` (`text-sm font-semibold`), `QuizListPage.vue` (`text-2xl font-semibold`), `Button.vue` (`text-sm font-medium`).

## Layout & Interaction Contracts

### LandingPage overall structure

```
AppHeader (sticky, h-14)
├── HeroSection          (py-16 desktop / py-12 mobile)
├── HowItWorksSection    (py-12, bg-neutral-900/50 tinted band)
├── QuizCarousel         (py-12)
├── PricingTeaserSection (py-12, bg-neutral-900/50 tinted band)
AppFooter
```

### HeroSection

- Full-width, centered text layout (`text-center max-w-3xl mx-auto`)
- Dot-grid backdrop already present globally via `#app::before` — no additional background needed
- Headline: Display size (36px mobile → 48px ≥md), semibold (`font-semibold`), `text-neutral-50`
- Sub-headline: 16px (`text-base`), weight 400, `text-neutral-400`, `mt-4`, line-height 1.5
- CTA row: `mt-8 flex flex-wrap justify-center gap-3`
  - **Primary (unauthenticated):** gradient button "Начать бесплатно" → `/auth`
    `bg-linear-to-r from-violet-600 to-indigo-600 text-white rounded-lg h-10 px-8 font-medium hover:opacity-90`
  - **Primary (authenticated):** orange button "Мои тесты" → `/my`
    Uses `Button` default variant (`bg-orange-500`)
  - **Secondary (both states):** ghost/outline "Смотреть тесты" → `/quizzes`
    Uses `Button` outline variant
- Auth-state detection via `useAuthStore().user` — same pattern as `AppHeader`

### HowItWorksSection

- Heading: "Как это работает", 20px semibold, `text-neutral-50`, `mb-8`
- 3 step cards in a `grid grid-cols-1 gap-6 sm:grid-cols-3` layout
- Each step card: `rounded-2xl border border-neutral-800 bg-neutral-900 p-6`
- Step counter: circular badge 32×32, `bg-linear-to-br from-violet-600 to-indigo-600 text-white text-sm font-semibold rounded-full flex items-center justify-center mb-4`
- Step title: 16px semibold, `text-neutral-50`, `mb-2`
- Step body: 14px regular, `text-neutral-400`, line-height 1.5
- Step content (draft copy — user will review):
  1. **"Загрузи текст"** — "Скопируй материал или загрузи файл PDF/DOCX — любой объём"
  2. **"AI создаёт тест"** — "Нейросеть за секунды генерирует вопросы с вариантами ответов"
  3. **"Поделись и проверяй"** — "Отправь ссылку участникам и сразу смотри результаты"

### QuizCarousel

- Section heading: "Свежие тесты", 20px semibold, `text-neutral-50`, left-aligned `mb-6`
- Sub-label: "Последние публикации · обновлено недавно", 14px, `text-neutral-400`
- Carousel viewport: `overflow-hidden`, full width, `rounded-2xl` optional outer clip
- Track: `flex gap-4 transition-transform duration-300 ease-in-out` — translate-based slide
- Card width: `w-64 shrink-0` (256px) — consistent with `QuizCard` fixed proportions
- Visible cards: 4 on desktop (≥1024px), 3 on tablet (≥768px), 1.5 on mobile (peek)
- Auto-advance: every 4000ms, pauses on `mouseenter`, resumes on `mouseleave`
- Controls:
  - Prev/Next arrow buttons: `h-11 w-11 rounded-full bg-neutral-800 border border-neutral-700 flex items-center justify-center text-neutral-300 hover:bg-neutral-700 hover:text-neutral-50 cursor-pointer transition-colors` — absolute positioned outside the track, vertically centered
  - Arrow icons: `lucide-vue-next` `ChevronLeft` / `ChevronRight`, `h-5 w-5`
  - Accessibility: icon-only buttons MUST declare `aria-label="Предыдущий"` (prev) and `aria-label="Следующий"` (next)
  - Disabled state: `opacity-40 pointer-events-none` when at first/last card
- "Смотреть все" link: `text-sm text-orange-400 hover:text-orange-300 underline-offset-2 hover:underline` — right-aligned in section header row
- Implementation: pure CSS scroll-snap as baseline (`scroll-snap-type x mandatory` on the container); JavaScript manages the auto-advance timer and programmatic scroll — no carousel library dependency required

### PricingTeaserSection

- Heading: "Простые тарифы", 20px semibold `text-neutral-50`
- Sub: "Начни бесплатно — перейди на Pro когда нужно", 14px `text-neutral-400`
- Layout: `grid grid-cols-1 gap-4 sm:grid-cols-2 max-w-2xl mx-auto mt-8`
- Free card: `rounded-2xl border border-neutral-800 bg-neutral-900 p-6`
  - Plan name "Free" 20px semibold, price "0 ₽", `text-neutral-50`
  - 3 highlight features: `text-sm text-neutral-300` with `Check` icon `text-neutral-500`
- Pro card: `rounded-2xl border border-violet-600/40 bg-neutral-900 p-6 ring-1 ring-violet-600/20`
  - Plan name "Pro" 20px semibold + gradient badge, price "490 ₽/мес", `text-neutral-50`
  - 3 highlight features with `Check` icon `text-violet-400`
  - CTA button "Подробнее о Pro" → `/billing`: `Button` outline variant, full width `w-full mt-4`
- Note: This teaser is a compact summary only — full feature list lives on `/billing` (Phase 5 PricingCards)
