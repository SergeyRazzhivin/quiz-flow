## Spacing Scale

Standard 8-point scale. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline spacing |
| sm | 8px | Compact element spacing, button icon gap |
| md | 16px | Default element spacing, card internal padding |
| lg | 24px | Section padding, card-to-card gap |
| xl | 32px | Layout vertical rhythm between sections |
| 2xl | 48px | Major section breaks (plan card to status banner) |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Touch targets for the period toggle (monthly/yearly): minimum 36px height so the toggle is comfortably tappable.
- Plan cards side-by-side gap: 24px (lg token) on desktop, stacked with 16px (md token) on mobile.

---

## Typography

Established by prior phases (Inter, dark theme). Billing page follows the same scale.

Two weights only: 400 (regular) and 600 (semibold). Labels and badges are distinguished from body text by size (12px), not weight.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Feature list items, plan description copy, status text, badge text, toggle labels, fine-print |
| Heading | 20px | 600 | 1.2 | Plan card titles ("Free", "Pro"), section headings |
| Display | 28px (text-2xl) | 600 | 1.2 | Page heading "Тарифы", price amount |
| Fine print | 12px (text-xs) | 400 | 1.4 | Badge chips ("PRO", "Скидка 24%"), usage meter text below feature list items |

Badge text ("Free", "Pro", "Скидка 24%") uses `text-xs` (12px, weight 400) to differentiate from body copy — no weight distinction needed.

Price display: 28px semibold for the number, 14px regular for the unit (₽/мес or ₽/год) — a consistent pattern with the project's stat display components.

## Color

Dark theme. Established in Phase 1. Billing page extends with a gradient accent for the Pro CTA.

| Role | Value | Usage | Source |
|------|-------|-------|--------|
| Dominant (60%) | `#0a0a0a` / `neutral-950` | Page background, overall surface | main.css |
| Secondary (30%) | `neutral-900` (#171717) | Plan cards background, header bar, period toggle track | AppHeader, Button.vue outline variant |
| Accent (10%) | violet-600 → indigo-600 gradient | Pro plan card border highlight, "Подписаться" Pro CTA button, "Pro active" badge background | CONTEXT.md specifics, main.css --color-brand-from/to |
| Orange accent | `orange-500` | "Тарифы" nav link active state (if needed), logo consistency | Button.vue default variant — do NOT use orange for the billing CTA; use gradient only |
| Destructive | `red-500` | Not used in this phase | Button.vue |

Accent reserved specifically for:
1. The "Подписаться" (Pro subscription) CTA button — gradient `from-violet-600 to-indigo-600` background.
2. The Pro plan card's top border accent line (2px, gradient).
3. The "Pro" badge on the Pro plan card header.
4. The "Pro активен" status badge in ProStatusBanner.

The orange-500 accent is NOT used for billing CTAs — it is reserved for quiz creation actions (established in prior phases). Mixing orange and violet on the same page would create visual conflict.

## Component Specs

### PricingCards.vue

**Period toggle:**
- Two buttons ("Помесячно" / "Ежегодно") rendered as a segmented control using the existing Tabs or a simple button pair.
- Active segment: `bg-neutral-700 text-neutral-50`, inactive: `text-neutral-400`.
- Yearly option shows a savings badge: `"Скидка 24%"` in a `text-xs rounded-full bg-violet-600/20 text-violet-400 px-2 py-0.5` chip.

**Free plan card:**
- Background: `bg-neutral-900 rounded-xl border border-neutral-800 p-6`
- Header: plan name "Free" in `text-xl font-semibold text-neutral-50`
- Price: "0 ₽" in display size
- Feature list — 14px body, `text-neutral-300`, checkmark icon `lucide:Check` in `text-neutral-500`
- CTA: disabled gray button `variant="secondary"` with label "Текущий план" when user is on Free; or no CTA if already Free (non-clickable state)
- Highlight: none (Free card is the subdued option)

**Pro plan card:**
- Background: `bg-neutral-900 rounded-xl border border-violet-600/40 p-6` (violet border to distinguish)
- Top accent line: `h-0.5 bg-gradient-to-r from-violet-600 to-indigo-600 rounded-t-xl -mt-6 -mx-6 mb-6` — 2px gradient bar at top of card
- Header: plan name "Pro" with a `"PRO"` badge: `text-xs bg-gradient-to-r from-violet-600 to-indigo-600 text-white rounded-full px-2 py-0.5`
- Price: "490 ₽" (monthly) or "4 490 ₽" (yearly) in display size + "/мес" or "/год" in 14px regular
- Feature list — 14px body, `text-neutral-300`, checkmark icon in `text-violet-400`
- CTA: gradient button with label "Подписаться" — `bg-gradient-to-r from-violet-600 to-indigo-600 text-white hover:opacity-90 h-10 rounded-md px-8 font-medium w-full`
- When Pro active: CTA replaced by "Продлить подписку" (outline variant, smaller) shown inside ProStatusBanner

**Feature list content (Free card):**
- 3 теста
- 10 вопросов на тест
- 10 AI-генераций в месяц
- Публичный доступ к тестам
- ~~Индивидуальные ссылки~~ (strikethrough, `line-through text-neutral-500`)
- ~~Статистика по вопросам~~ (strikethrough)

**Feature list content (Pro card):**
- Неограниченно тестов
- Неограниченно вопросов
- 30 AI-генераций в месяц
- Публичный доступ к тестам
- Индивидуальные ссылки доступа
- Статистика точности по вопросам

### ProStatusBanner.vue

Displayed above plan cards when user's effective plan is Pro and `period_end` is in the future.

```
bg-violet-600/10 border border-violet-600/30 rounded-xl px-6 py-4
├── Left: icon Sparkles (text-violet-400, h-5 w-5) + text "Pro активен"
│         sub-text: "Действует до DD.MM.YYYY" (text-sm text-neutral-400)
└── Right: Button variant="outline" size="sm" "Продлить подписку"
```

Date format: `DD.MM.YYYY` — use `toLocaleDateString('ru-RU')`.

### LimitBlockToast.vue

Not a separate toast component but a handler in the feature store that calls `toast.error(message, { action: { label: 'Перейти на Pro', onClick: () => router.push('/billing') } })` using vue-sonner's action API.

---

## Interaction States

| Interaction | State | Visual |
|-------------|-------|--------|
| Period toggle switch | Animated | Instant class swap, no animation needed — keep it simple |
| "Подписаться" button click | Loading | Button shows spinner icon + "Переходим к оплате…" text, `disabled` |
| Redirect to YooKassa | Navigation | `window.location.href` — browser navigates away; no in-app state |
| Return from YooKassa | On mount | BillingPage calls `fetchUsage()` in `onMounted`; shows updated plan immediately |
| Limit blocked (quiz creation) | Toast | `toast.error('Достигнут лимит тестов Free-плана.', { action: { label: 'Перейти на Pro', onClick: ... } })` |
| Limit blocked (question creation) | Toast | `toast.error('Достигнут лимит вопросов Free-плана (10).', { action: { label: 'Перейти на Pro', onClick: ... } })` |
| Limit blocked (AI generation) | Toast | `toast.error('Достигнут лимит AI-генераций (10/мес).', { action: { label: 'Перейти на Pro', onClick: ... } })` |

---

## Usage Meter (UX hints)

Displayed in small `text-xs text-neutral-400` below each limit item on the Free plan card — only when `usage` data is loaded and plan = 'free':

- "2 из 3 тестов" — quiz count
- "X из 10 AI-генераций в этом периоде"

These use data from `usePaymentStore.usage` (`quizzes_used`, `ai_used`, limits). Not shown to Pro users (no limits to meter).
