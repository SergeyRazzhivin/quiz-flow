Build the server foundation for AI quiz generation: the `ai_jobs` tracking table and the
single owner-authenticated `ai-generate-quiz` Edge Function that runs the OpenAI pipeline
asynchronously via `EdgeRuntime.waitUntil()`.

generation backend is fully callable — the request returns `{ jobId }` in <200 ms while
generation runs in the background and the result lands in the standard `quizzes` tables.

its `deno.json` import map, and the pushed schema.

client polls `ai_jobs` directly via owner-SELECT RLS, per RESEARCH Assumption A2 / Pattern 2.
