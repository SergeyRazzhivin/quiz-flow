  <action>
    Create `useQuizStatsStore` (composition-API `defineStore('quiz-stats', () => {...})`) per RESEARCH Pattern 2. Export interfaces `PerPersonRow`, `AccuracyRow`, `QuizStats`.

    State refs: `stats` (`QuizStats | null`), `accuracy` (`AccuracyRow[] | null`), `isPro` (boolean), `isLoading` (boolean), `error` (`string | null`). Computed `completionRate` = rounded `finishedCount / totalAttempts * 100`, returns `0` when no attempts.

    `loadStats(quizId: string)`: set `isLoading`, in try/catch — first `await loadProStatus()`, then call `supabase.rpc('get_quiz_stats', { p_quiz_id: quizId })` and assign `stats`. ONLY when `isPro.value === true`, call `supabase.rpc('get_quiz_accuracy', { p_quiz_id: quizId })` and assign `accuracy` (D-06 / Pitfall 1 — never fetch accuracy for Free owners). On catch set `error = 'Не удалось загрузить статистику'` and `toast.error('Не удалось загрузить статистику. Проверьте подключение и попробуйте обновить страницу.')`. `finally` clears `isLoading`.

    `loadProStatus()`: read `supabase.from('subscriptions').select('plan, status').eq('user_id', authStore.user.id).maybeSingle()`; set `isPro.value = data?.plan === 'pro' && data?.status === 'active'` — `maybeSingle()` + optional chaining handles the missing-row case for Free users (Pitfall 5). Return early if no `authStore.user`.

    Provide a `$reset()` clearing all refs. Return `{ stats, accuracy, isPro, isLoading, error, completionRate, loadStats, $reset }`.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Free owner client → accuracy data | A Free owner must never receive per-question accuracy numbers |
| unauthenticated visitor → /quiz/:id/stats | Owner-only route must be guarded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Elevation of Privilege | useQuizStatsStore.loadStats | mitigate | `get_quiz_accuracy` RPC is called only inside `if (isPro.value === true)`; Free clients never receive accuracy data — the Pro gate is "do not fetch", not visual blur (D-06) |
| T-04-05 | Information Disclosure | /quiz/:id/stats route | mitigate | Route registered with `meta: { requiresAuth: true }`; the existing router guard redirects unauthenticated visitors to /auth. The underlying RPCs (Plan 04-01) re-verify quiz ownership server-side |
| T-04-06 | Spoofing / Tampering | subscriptions read | mitigate | `isPro` derived from a `subscriptions` row read under owner RLS for `user_id = auth.uid()`; a client cannot read or forge another user's subscription |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No packages installed in this phase (RESEARCH: zero new dependencies) |
</threat_model>
