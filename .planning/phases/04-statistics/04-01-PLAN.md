    get_quiz_stats(p_quiz_id uuid) RETURNS jsonb, LANGUAGE plpgsql SECURITY DEFINER STABLE. First statement MUST select quizzes.owner_id into a local v_owner_id and RAISE EXCEPTION 'unauthorized' when it IS DISTINCT FROM auth.uid() (per RESEARCH Pitfall 2 — DEFINER bypasses RLS). Return a jsonb_build_object with keys: totalAttempts (D-03 — COUNT all started quiz_sessions for the quiz), finishedCount (D-03 — COUNT where finished_at IS NOT NULL; the completion-rate numerator/denominator are both computed over ALL sessions, not latest-per-person), avgScore (D-02/D-04 — AVG over DISTINCT ON (quiz_access_id) score ordered by finished_at DESC — latest finished attempt per taker), totalQuestions (COUNT questions for the quiz — RESEARCH Open Question #1), perPerson (D-02 — jsonb_agg of DISTINCT ON (quiz_access_id) rows joining quiz_access.label as name, score, finished_at, ordered by quiz_access_id then finished_at DESC — one row per taker, their latest finished attempt). avgScore over an empty set is NULL — leave it NULL, the client renders the dash.

    get_quiz_accuracy(p_quiz_id uuid) RETURNS jsonb, same modifiers and same ownership check first. Body computes per-question accuracy_percent (D-04 — from latest finished attempts only): for each question (questions WHERE quiz_id = p_quiz_id, ordered by order_index), the % of latest-finished-per-taker sessions whose answer to that question contains a correct option. Use the LEFT JOIN LATERAL form from RESEARCH (DISTINCT ON latest session per quiz_access_id, then session_answers, then bool_or(answer_options.is_correct) over unnest(selected_option_ids)). ROUND to 1 decimal, NULLIF guard on the denominator. Return jsonb_agg of {question_id, body, order_index, accuracy_percent}.

    End the file with GRANT EXECUTE ON FUNCTION get_quiz_stats(uuid) TO authenticated; and the same GRANT for get_quiz_accuracy(uuid). Do NOT grant to anon. answer_options.is_correct is read only inside this function body and is never a key in either returned payload.
