## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure / Elevation | get_quiz_stats / get_quiz_accuracy SECURITY DEFINER | mitigate | First statement in each RPC verifies `owner_id = auth.uid()` and `RAISE EXCEPTION 'unauthorized'` on mismatch — prevents horizontal privilege escalation to another owner's data |
| T-04-02 | Information Disclosure | answer_options.is_correct | mitigate | `is_correct` is read only inside the DEFINER RPC body; the RPC returns only aggregate `accuracy_percent`, never the raw column |
| T-04-03 | Elevation of Privilege | RPC grants | mitigate | `GRANT EXECUTE ... TO authenticated` only; no `anon` grant — guest/anon role cannot call the stats RPCs |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No packages installed in this phase (RESEARCH: zero new dependencies) |
</threat_model>
