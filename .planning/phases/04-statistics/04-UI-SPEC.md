# Phase 4 — UI Design Contract

> Visual and interaction contract for the owner-facing statistics page (`/quiz/:id/stats`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn-vue CLI broken on Node 20 — components hand-crafted with radix-vue + CVA, per STATE.md) |
| Preset | not applicable |
| Component library | radix-vue 1.9 + class-variance-authority |
| Icon library | lucide-vue-next |
| Font | Inter (`--font-sans`, defined in `src/1-app/styles/main.css`) |

Theme: permanent dark theme. Base surface `#0a0a0a`, base text `#fafafa` (set on `html, body, #app`). No light mode.

**Reuse existing shared components — do not re-build:**
- `6-shared/ui/Button.vue` — variants `default` (orange), `outline`, `secondary`, `ghost`, `link`; sizes `default/sm/lg/icon`.
- `6-shared/ui/ProgressBar.vue` — `value: 0–100`, `h-1` track. NOTE: too thin for per-question accuracy bars; this phase needs a thicker bar (see Visuals below) — extend ProgressBar with a `size` prop or add a dedicated `StatBar` in the `quiz-stats` feature slice.
- `6-shared/ui/Tooltip.vue` — for the blurred Pro section explainer if needed.
- `6-shared/lib/format.ts` — `formatDuration`; add a `formatScore` / `formatPercent` helper here if not present.

## Spacing Scale

Declared values (Tailwind v4 default scale, multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside cards/buttons |
| sm | 8px | Card label-to-number gap, table cell vertical padding |
| md | 16px | Default gap inside cards, table cell horizontal padding |
| lg | 24px | Card internal padding, gap between summary cards |
| xl | 32px | Vertical gap between page sections (summary / table / accuracy) |
| 2xl | 48px | Page top padding below the app header |
| 3xl | 64px | Empty-state vertical breathing room |

Page content max width: `max-w-5xl` (1024px), centered, with `px-4` gutters on mobile.
Exceptions: none.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 36px (`text-4xl`) | 600 semibold | 1.2 | Large summary-card numbers (total attempts, %, avg score) |
| Heading | 20px (`text-xl`) | 600 semibold | 1.2 | Page title "Статистика", section headings |
| Body | 16px (`text-base`) | 400 regular | 1.5 | Table cell text, empty-state body, CTA explainer |
| Label | 13px (`text-[13px]`) | 400 regular | 1.4 | Card metric labels, table column headers (uppercase, `tracking-wide`, `text-neutral-400`) |

Two weights only: 400 regular, 600 semibold. Three working sizes (Display/Heading/Body) plus the Label micro-size — within the 3–4 size budget.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0a0a` (page bg) | Page background, overall surface |
| Secondary (30%) | `neutral-900` `#171717` cards / `neutral-800` `#262626` table-header & dividers | Summary cards, accuracy panel, table rows |
| Accent (10%) | `orange-500` `#f97316` | See reserved list below |
| Destructive | `red-500` `#ef4444` | Not used in Phase 4 (no destructive actions) — reserved only |

Borders: `border-neutral-800` on cards and table; muted text `text-neutral-400`.

**Accent (orange-500) reserved for — explicit list:**
- The progress-bar fill on per-question accuracy bars.
- The "Перейти на Pro" upgrade CTA button (Button `default` variant).
- The active link/hover state of the "Статистика" entry buttons.
- Nothing else. Summary-card numbers are `#fafafa` (not orange); table content is neutral; the page must not become orange-heavy.

Pro-gate blur: the per-question accuracy section for Free owners renders behind a `backdrop-blur-md` overlay with a darkened scrim (`bg-neutral-950/60`) and a centered upgrade CTA card. Underlying numbers are NOT fetched for Free owners (per CONTEXT D-06) — render placeholder skeleton bars beneath the blur, never real data.

## Component & Layout Inventory

| Element | Spec |
|---------|------|
| Page shell | `2-pages/QuizStatsPage.vue` — thin assembler under the existing app header + auth guard. `min-h-[100dvh]`, never `100vh`. |
| Summary cards | 3 cards in a responsive grid (`grid-cols-1 sm:grid-cols-3 gap-6`). Each: `bg-neutral-900 border border-neutral-800 rounded-xl p-6`. Layout: Label (top, 13px neutral-400 uppercase) → Display number → optional unit suffix. |
| Per-person table | `bg-neutral-900 border border-neutral-800 rounded-xl overflow-hidden`. Header row `bg-neutral-800` Label-style. Body rows separated by `border-t border-neutral-800`, row hover `hover:bg-neutral-800/50`. Columns: Имя, Балл, Завершён. Default sort: completion timestamp descending (latest first). |
| Accuracy bars | One row per question: question text (Body, truncate) + horizontal bar + `%` value (right-aligned, semibold). Bar: `h-2 rounded-full bg-neutral-800` track, `bg-orange-500` fill, `transition-all duration-300`. Wrapped in `bg-neutral-900 border border-neutral-800 rounded-xl p-6`. |
| Pro blur overlay | Absolute overlay over the accuracy panel: `backdrop-blur-md bg-neutral-950/60`, centered card with lock icon (`lucide-vue-next` Lock), short copy, and the upgrade CTA button. |
| Empty state | Centered block, `py-16` (`3xl`-ish): lucide `BarChart3` or `Inbox` icon (48px, `text-neutral-600`), heading, body copy. No zeroed cards, no error styling. |
| Loading state | Skeleton: card and bar shapes with `animate-pulse bg-neutral-800`. |
| Rounding | Cards/panels `rounded-xl` (12px); buttons keep their existing `rounded-md`; bars `rounded-full`. |

## Interaction Contract

- Entry buttons (`Статистика`): on `/my` quiz card use Button `outline` `sm`; in `QuizEditorHeader.vue` use Button `outline` `sm`. Both navigate to `/quiz/:id/stats`.
- Page is read-only — no mutations, no destructive actions, no confirmation dialogs.
- Loading: show skeletons (not a blank screen) while the owner stats read is in flight.
- Free owner: accuracy panel always renders, blurred, with the CTA. The CTA navigates toward the Phase 5 pricing route (placeholder route until Phase 5 ships — link target is a planning decision; do not block on it).
- Table: latest-finished-attempt-per-person only (CONTEXT D-02). If only in-progress attempts exist, the table is empty but the summary still shows started-count via completion rate.
- Responsive: summary cards stack to a single column below `sm`; the table allows horizontal scroll (`overflow-x-auto`) rather than reflowing on narrow viewports.
