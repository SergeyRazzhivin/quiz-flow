# Requirements: Quiz Flow

**Defined:** 2026-05-16
**Core Value:** Пользователь загружает текст — AI генерирует готовый тест за секунды, который можно сразу отправить тестируемым.

---

## v1 Requirements

### Authentication

- [ ] **AUTH-01**: Пользователь может зарегистрироваться по email и паролю
- [ ] **AUTH-02**: Пользователь может войти по email и паролю и оставаться в системе после перезагрузки страницы
- [ ] **AUTH-03**: Пользователь может выйти из аккаунта с любой страницы

### Quiz Management

- [ ] **QUIZ-01**: Пользователь может создать новый тест с названием, описанием, обложкой и лимитом времени
- [ ] **QUIZ-02**: Пользователь может редактировать метаданные теста (название, описание, обложка до 1280px, лимит времени)
- [ ] **QUIZ-03**: Пользователь может публиковать и снимать тест с публикации
- [ ] **QUIZ-04**: Пользователь может видеть список всех своих тестов на странице «Мои тесты»
- [ ] **QUIZ-05**: Пользователь может видеть список всех опубликованных тестов на главной странице
- [ ] **QUIZ-06**: Пользователь может удалить свой тест
- [ ] **QUIZ-07**: Обложка теста загружается в Supabase Storage

### Question Editor

- [ ] **EDIT-01**: Пользователь может добавлять вопросы в тест
- [ ] **EDIT-02**: Пользователь может редактировать текст вопроса и тип (single / multiple)
- [ ] **EDIT-03**: Пользователь может отмечать вопрос как обязательный или необязательный
- [ ] **EDIT-04**: Пользователь может добавлять, редактировать и удалять варианты ответов к вопросу
- [ ] **EDIT-05**: Пользователь может отмечать варианты ответов как правильные
- [ ] **EDIT-06**: Пользователь может менять порядок вопросов через drag-and-drop
- [ ] **EDIT-07**: Пользователь может удалять вопросы
- [ ] **EDIT-08**: Редактор теста имеет фиксированный header (метаданные), скроллируемый body (список вопросов) и фиксированный footer (настройки навигации)

### Navigation Settings

- [ ] **NAV-01**: Пользователь может настраивать кнопки навигации для тестируемого («Назад», «Вперёд», «Стоп»)
- [ ] **NAV-02**: Пользователь может включать/выключать возможность возврата к предыдущему вопросу

### AI Wizard

- [ ] **AI-01**: Пользователь может открыть 4-шаговый визард для AI-генерации теста
- [ ] **AI-02**: Пользователь может ввести название теста (шаг 1)
- [ ] **AI-03**: Пользователь может загрузить файл (PDF/DOCX) или ввести текст/промпт как исходный материал (шаг 2)
- [ ] **AI-04**: Пользователь может уточнить параметры генерации: количество вопросов, сложность, область фокуса (шаг 3)
- [ ] **AI-05**: Система генерирует тест через Supabase Edge Function → OpenAI API → JSON → парсинг в БД (шаг 4)
- [ ] **AI-06**: После генерации пользователь перенаправляется в обычный редактор теста
- [ ] **AI-07**: Во время генерации отображается прогресс-индикатор с понятными сообщениями на русском языке

### Quiz Sharing (Pro)

- [ ] **SHARE-01**: Пользователь (Pro) может создать индивидуальную ссылку доступа с логином, паролем и именем тестируемого
- [ ] **SHARE-02**: Пользователь (Pro) может установить срок действия ссылки
- [ ] **SHARE-03**: Пользователь (Pro) может просматривать и удалять ссылки доступа

### Quiz Taking (Guest)

- [x] **TAKE-01**: Тестируемый может открыть тест по токен-ссылке (/q/:token) без авторизации на сайте
- [x] **TAKE-02**: Тестируемый вводит логин и пароль для доступа к тесту
- [x] **TAKE-03**: Тестируемый видит название, описание и обложку теста перед началом
- [ ] **TAKE-04**: Тестируемый отвечает на вопросы по одному с навигацией (следующий/предыдущий — в зависимости от настройки allow_back)
- [ ] **TAKE-05**: Тестируемый видит прогресс прохождения (Вопрос X из Y) и оставшееся время
- [ ] **TAKE-06**: Тестируемый может завершить тест досрочно
- [ ] **TAKE-07**: Ответы сохраняются немедленно при выборе (upsert в session_answers), не только при финальном сабмите
- [ ] **TAKE-08**: После завершения тестируемый видит страницу результата (счёт, процент)
- [ ] **TAKE-09**: Таймер основан на серверном `started_at` — вычисляется от сервера, не декрементируется клиентом
- [ ] **TAKE-10**: Тест автоматически отправляется по истечении времени

### Statistics

- [ ] **STATS-01**: Владелец может видеть общее количество попыток, процент завершений и средний балл по тесту (Free)
- [ ] **STATS-02**: Владелец может видеть таблицу результатов по каждому тестируемому (имя, балл, время завершения) (Free)
- [ ] **STATS-03**: Пользователь (Pro) может видеть точность по каждому вопросу (% правильных ответов)

### Freemium & Billing

- [ ] **PAY-01**: Free план: лимит 3 теста, 10 вопросов на тест, 1 AI-генерация в месяц; индивидуальные ссылки недоступны
- [ ] **PAY-02**: Пользователь может видеть страницу тарифов с описанием Free и Pro планов
- [ ] **PAY-03**: Пользователь может оформить подписку Pro (490 ₽/мес) через ЮKassa
- [ ] **PAY-04**: Лимиты плана enforced на уровне БД/Edge Function — не только на клиенте
- [ ] **PAY-05**: При отмене/истечении подписки права Pro автоматически отзываются

## v2 Requirements

### Качество тестов

- **QA-01**: Перемешивание вариантов ответов (`shuffle_answers` флаг) — схема требует дополнения
- **QA-02**: Переключатель «Показывать правильные ответы» на странице результатов (владелец)

### Дополнительные возможности

- **EXT-01**: Годовая подписка Pro (4 490 ₽/год, скидка ~24%)
- **EXT-02**: Дата истечения ссылки — UI в редакторе (схема уже поддерживает)
- **EXT-03**: Перемешивание порядка вопросов (`shuffle_questions` — уже в settings JSONB)
- **EXT-04**: Повторные попытки по той же ссылке
- **EXT-05**: Распределение результатов по баллам (гистограмма)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Мобильное приложение | Веб-first; нативный клиент не запланирован |
| Командная работа / совместное редактирование | Усложняет MVP; нет запроса от ЦА |
| Встроенный чат или комментарии | Не core value; social feature |
| Экспорт тестов в PDF/Word | Постмвп; нужна дополнительная инфраструктура |
| OAuth (Google, GitHub) | Email/password достаточно для v1 |
| Вопросы с открытым ответом (essay) | Требует ручной проверки; ломает автоподсчёт |
| Массовый импорт из CSV/Excel | AI-визард — лучший путь для массовой генерации |
| Встраивание в сторонние сайты | iFrame усложняет QA; прямая ссылка достаточна |
| Прокторинг (камера, отслеживание вкладок) | Enterprise feature; не целевая аудитория |
| Email-уведомления тестируемым | У тестируемых нет аккаунта для email |
